# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately through GitHub instead: on the
[Security tab](https://github.com/open-shipyard/robinauts/security), choose
**Report a vulnerability**. Include what you found, how to reproduce it, and
what an attacker could do with it.

## What to expect

Robinauts is maintained by a small team, so these are best-effort targets:

- An acknowledgement within 3 days.
- A first assessment, and a plan if the report is confirmed, within 14 days.
- A fix and public disclosure within 90 days of the report, sooner when the
  fix is ready. If more time is needed, we agree on it with you.

You will be credited in the advisory unless you prefer not to be.

## Supported versions

Robinauts has not made a release yet. Fixes go to the `main` branch only.
