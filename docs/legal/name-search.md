# Name search

The name of the project is **Robinauts**. The project owner decided it
(2026-09-21).

**The record of how the name was checked is not in the repository yet.** A
foundation that adopts a project takes over its name as a trademark, and
asks for that record. Until it is here, nobody should report the name as
searched on the strength of this file.
